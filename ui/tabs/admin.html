2. Cấu hình CSKCB & Tích hợp API HIS

Cấu hình thông tin cơ sở khám chữa bệnh và kết nối API HIS nội bộ để đồng bộ bệnh nhân.

Cấu hình Tích hợp HIS (2 Chế độ)
Chọn phương thức đồng bộ bệnh nhân từ phần mềm HIS bệnh viện vào Máy chủ KSK.
Chế độ Mock API HIS nội bộ (Thử nghiệm khi chưa nối HIS thật)
Khi BẬT: tự động trả về dữ liệu mẫu (TN.2611.0004018, TN.2611.0004019...). Khi TẮT: đăng nhập lấy Token và gọi API HIS thật.
* Hệ thống tự động thay thế {{ma_tn}} bằng Mã tiếp nhận cần tìm.
Hướng dẫn Chế độ 2 (AutoHotkey v2 UIA Bridge qua HTTP API):
  • Chạy ahk/his_tiep_nhan_bridge.ahk trên máy trạm tiếp nhận có mở phần mềm HIS.
  • Cấu hình địa chỉ máy chủ (VD: http://<IP_MAY_CHU>:8080) và đăng nhập bằng tài khoản Tiếp nhận.
  • Khi đứng trên màn hình tiếp nhận của HIS, nhấn F9 để hiện hộp thoại Xác nhận thông tin trước khi đẩy qua API POST /api/his/push lên máy chủ.
